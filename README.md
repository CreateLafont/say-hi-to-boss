# Say Hi to Boss

这是一个面向 Codex、WorkBuddy、豆包、QwenWork、AutoGLM 等 AI Agent 的 Skill，根据简历与岗位 JD 生成 100–150 字的中文定制招呼语。作品集可选；只生成文案，不自动发送消息或投递简历。

## 使用

按所用 Agent 的 Skill 导入方式加载本目录。在 Codex 中，可将本目录放入 ~/.codex/skills/，使用 $say-hi-to-boss。先提供简历（作品集可选），再发送岗位 JD 截图或文本；同一会话可复用已提供的经历。

本仓库不包含候选人简历、岗位截图或对话记录。
